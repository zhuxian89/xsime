- 数据包：`XSIME-Ice-Pinyin-9Key-20261028.zip`，10,007,233 字节。iOS 产品代码和 IPA 未修改。
- 来源：iDvel/rime-ice `da1fbe602e38f26db846fa10120ee64c2b0324c0`，包含 8105、base、ext、others，共 891,966 条记录（含多音字/词读音，不是去重后的词数）。
- 修改：保留词条、权重和来源注释；为兼容导入器平铺词典文件名并改对应 name；添加全拼和 T9 源方案。包内包含许可、来源校验和完整可编辑源数据。
- 配方提交：`56c9f6ff194e8f55257eae9ce1abeeb3cbac1508`。
- [验证 CI](https://github.com/zhuxian89/xsime/actions/runs/40667240215)：成功。使用未修改的 iOS Swift 导入器检查和暂存，再用 iOS 引擎的 host slice 编译、加载、试打；没有运行本地产品构建或测试。
- 13 组候选检查通过；你好、微信、抖音、小红书在全拼和九宫格下的 8 组首选断言通过。部署产物约 55 MiB，CI 主机部署峰值约 555 MiB；这不是键盘常驻内存或手机性能数据。
- SHA-256：`279cf4353bd27dc1921461d44f851b3f2f5ef62185eb58c85dbd6674fae6eedc`。本地交付 ZIP 与远端被验证的 ZIP 摘要一致。

## 排序限制与验证边界

[首次检查](https://github.com/zhuxian89/xsime/actions/runs/40666628158) 导入、编译和加载均成功，但把“九宫格 3294 的搭子必须在前 10”作为覆盖断言导致失败。
该编码还对应法医、答疑、打字、大一等词，不能把收录等同于该词应优先。第二轮没有修改词频来迎合测试：保留这项排序限制，验证明确选定 `da'zi` 后可出现搭子，同时保留 3294 的打字候选检查，并为现代常用词增加首选断言。

干净用户库下，九宫格的晚安排第 4；搭子不在未限定拼音的前 10。增加词库覆盖不等于达到豆包的排序和预测能力。此包是固定快照，没有自动热词更新。

真机验收待用户完成：在 68 的“Rime 方案包与导入”中选 ZIP，勾选全拼、九宫格并部署，启用九宫格后检查普通宿主/Buffer 的候选、拼音选择、学习、内存与速度。原内置学习库不合并、不删除，可恢复内置方案。
