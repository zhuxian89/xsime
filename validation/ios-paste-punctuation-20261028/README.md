# iOS Buffer 粘贴与九宫格标点

## 问题与改动

用户在 iOS 17 / TrollStore 使用“暧昧搭子”时，Buffer 输入行长按没有粘贴入口；
九宫格常用标点需要先打开候选栏标点，再选符号。用户提供搜狗截图，希望常用标点直接列在左侧。

- `SingleLineTextView` 原为单行标签与滚动容器，并非原生文本编辑器，没有编辑菜单。
  现在用 `UIEditMenuInteraction` 提供长按“粘贴”，不争抢宿主文本框的第一响应者。
- 打开菜单不读剪贴板。点击粘贴后才读取，并沿用 `PendingPaste` 处理系统授权弹窗。
  过期菜单、输入框或插件切换、源文本或光标变化均拒绝旧操作。
- 文本插入当前光标，已有选区则替换；保留 emoji、空格和换行，限制 Buffer 为 16 KiB。
  粘贴清除旧 AI 结果并暂停自动上屏，用户明确执行后才发送。
- 九宫格左侧常驻可滚动标点栏，首屏为 `，。？！`，继续滑动可选 `、：；……/“”（）`。
  点标点先确认当前拼音候选，再通过现有 Buffer / 宿主投递路径插入。
  “选拼音”移至中央九宫格左上，“符号”位于左下，26 键与自定义布局不改。
- 设置页预览同步反映标点栏；兼容标识、共享钥匙串、App Group 与数据路径保持不变。

## iOS 17 真机验收待确认

1. 用 TrollStore 覆盖安装 68，检查原有配置与键盘完全访问仍可用。
2. 复制对方消息，打开搭子，长按输入行点“粘贴”：文本留在输入行，点 ▶ 才执行。
3. 在空输入行和已有草稿中分别粘贴；首次系统询问粘贴权限时允许后检查草稿。
4. 九宫格左侧点逗号、句号、问号、感叹号，再向上滑选其他符号；滑动本身不应输入。
5. 普通聊天和 Buffer 中分别输入拼音后点标点，检查汉字与标点的顺序、候选和光标。

自动化与截图不替代真机长按、系统跨 App 粘贴授权和滚动触感验收。
