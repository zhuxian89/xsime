# 中英文切换键位置一致

问题：九宫格的中英文切换键位于空格右侧，但切换到英文 QWERTY 后出现在空格左侧，导致用户必须换位置操作。

修复：标准 QWERTY、数字和符号页的底行统一为 `123 | 空格 | 中/英 | 回车`，与九宫格一样将语言键置于空格右侧、回车左侧。保留原有按键宽度、输入逻辑和九宫格布局；设置预览复用同一几何布局。

已有布局回归同步检查四种标准页面在横竖屏尺寸下的顺序、边界和间隔，并在现有九宫格切英文用例中保留英文截图。

目标交付：1.2.0 (69) TrollStore IPA。沿用原标识与用户数据位置，已导入雾凇方案无需重新导入。

验证：待远端 CI 与产物核对；iOS 17 真机位置和切换体验待用户确认。
